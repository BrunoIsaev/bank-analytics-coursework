# homework-10
Homework project for processing banking data


## Поиск и анализ транзакций (Домашка 16)

Реализована логика поиска операций и интерактивное консольное меню.

### Новые функции (src/bank_operations.py)
- **process_bank_search(data, search)**: Ищет операции по описанию с использованием регулярных выражений (re).
- **process_bank_operations(data, categories)**: Подсчитывает количество операций по категориям с использованием Counter.

### Главный модуль (src/main.py)
- Реализована функция main() с пользовательским интерфейсом.
- Поддерживается выбор формата файла (JSON, CSV, XLSX).
- Доступна фильтрация по статусу, дате, валюте и ключевым словам.
- Обработка некорректного ввода пользователя без падения программы.

### Тестирование
- Написаны тесты для новых функций (9 тестов, все passed).
- Код прошел проверку flake8 (0 ошибок) и isort.
